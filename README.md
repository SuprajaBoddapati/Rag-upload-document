# 📚 RAG Document Question Answering Application

A Full Stack Generative AI application that allows users to upload PDF documents and ask intelligent questions using Retrieval-Augmented Generation (RAG), semantic search, and vector embeddings.

---

# 🚀 Features

- PDF Upload
- Document Chunking
- Semantic Search
- FAISS Vector Database
- LangChain Integration
- HuggingFace Embeddings
- FastAPI Backend
- React + TypeScript Frontend
- Conversational Question Answering
- MMR Retrieval
- Hybrid Search Concepts

---

# 🛠️ Tech Stack

## Frontend
- React.js
- TypeScript
- Axios
- CSS

## Backend
- FastAPI
- Python
- LangChain
- FAISS
- HuggingFace Transformers
- Sentence Transformers

---

# ⚡ How It Works

1. Upload PDF document
2. Extract document text
3. Split into chunks
4. Generate embeddings
5. Store vectors in FAISS
6. Retrieve relevant chunks
7. Generate answers using LLM
